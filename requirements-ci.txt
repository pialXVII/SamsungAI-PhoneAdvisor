# Runtime + test dependencies for CI and the Docker image.
#
# Same as requirements.txt minus CrewAI, plus httpx. Install CPU-only torch
# FIRST so pip does not pull the ~2.5 GB CUDA build:
#
#   pip install torch --index-url https://download.pytorch.org/whl/cpu
#   pip install -r requirements-ci.txt
#
# Why CrewAI is left out: it brings ~70 packages (chromadb, lancedb,
# opentelemetry, ...) and only runs when an LLM is loaded. CI and the default
# container run with USE_LLM=false, where src/agents/crewai_backend.py reports
# CrewAI unavailable and the native orchestrator answers instead, so installing
# it would add minutes and hundreds of MB without exercising any of it. Build
# the image with --build-arg WITH_CREWAI=true to include it.
